# Данные

- `examples/demo-dataset.json` — синтетический публичный пример. Vite раздаёт его по `/demo-dataset.json` и копирует в сборку; это единственная копия примера импорта в репозитории.
- `raw/` — локальные исходные CSV, не отслеживаются Git. Получите их у команды; проект работает без них на демоданных.
- `processed/` — локальные результаты преобразования и геокодирования, не отслеживаются Git.

`frontend/src/demo.ts` задаёт стартовый сценарий интерфейса и срочную заявку. JSON в `examples/` предназначен для демонстрации импорта.

Для новых опубликованных примеров указывайте источник и синтетические допущения. Не помещайте исходные данные в `examples/`: всё содержимое этой папки доступно посетителям сайта.
