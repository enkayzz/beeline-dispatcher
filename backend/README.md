# Серверная часть

Каталог для API, базового алгоритма, оптимизатора и их тестов. Сервер пока не реализован; запуск фронтенда от него не зависит. Демонстрационный алгоритм находится в `../frontend/src/api.ts`.

Начать с [контракта API](../docs/API_CONTRACT.md) и [плана команды](../docs/ACTION_PLAN.md). Требуются `POST /api/plans` и `POST /api/plans/replan`.

При реализации храните исходники в `src/`, тесты в `tests/`, зависимости и команды запуска — здесь. Проверки сервера добавьте отдельной задачей в `.github/workflows/ci.yml`. Не меняйте формат API без синхронного обновления фронтенда и документации.
