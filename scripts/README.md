# Скрипты проекта

Здесь размещаем утилиты преобразования CSV, геокодирования и подготовки демонаборов. Реализованных утилит пока нет.

Каждый скрипт должен описывать зависимости, пример запуска из корня репозитория и входные/выходные файлы. По умолчанию читать `data/raw/`, писать в `data/processed/`, не изменять оригиналы и не хранить ключи API в коде. При появлении зависимостей фиксировать их рядом со скриптами.
